# 日周月全市场扫描服务

该服务把用户提供的博主日周月体系固化为可审计的规则引擎，并通过统一网关提供接口。周期优先级为月线、周线、日线；扫描只自动判定资料中明确且可由OHLCV计算的条件。

## 接口

- `GET /health`：健康检查。
- `GET /api/stocks/rules`：查看自动规则和人工核对项。
- `GET /api/stocks/universe`：获取沪深股票池。
- `GET /api/stocks/{code}`：逐条核对单只股票，例如 `600360`。
- `POST /api/stocks/scan`：全市场扫描。请求体可传 `{"exclude_risk": true, "max_workers": 8}`。

## 自动化边界

自动规则包括：月线站上60月线、月线5/10/20/60多头、最近3个完整月站上5月线、周线5/10/20多头且20周线上行、日线5/10/20多头，以及新增资料明确给出的周线20周线突破量能1.5倍和阳包阴量能1.5倍等观察字段。

圆弧底、箱体回踩、双底、头肩底、分时承接、盘口主力行为、筹码峰和获利比例等需要图形、逐笔或专门筹码数据的项目返回 `insufficient`，不会被自动猜测。资料中没有明确距离阈值的“回踩5/10日线”也不作为硬筛选条件。

## 数据源说明

默认从东方财富公开行情接口获取沪深股票池，从Yahoo Finance公开Chart接口获取日线OHLCV，再在本地聚合完整周线和月线。服务严格排除当前未结束周/月，避免把盘中数据当成确认信号。公开行情接口可能临时限流或返回502；服务会重试，若不能获取完整股票池则返回错误，不静默地把部分市场当成全市场。

## 启动

在仓库根目录执行 `docker compose up -d stock-scanner api-gateway`，扫描服务地址为 `http://localhost:8010`，统一网关地址为 `http://localhost:8000/api/stocks`。前端入口位于“概览 → 日周月扫描”。

> 本服务提供规则核对和研究辅助，不构成收益保证、个性化投资建议或自动交易执行。
